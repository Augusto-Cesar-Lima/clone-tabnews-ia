# AGENTS.md

Orientações para agentes de IA trabalharem neste repositório.

## Sobre o projeto

`clone-tabnews-ia` é um clone do [TabNews](https://www.tabnews.com.br), o projeto prático do curso.dev (Filipe Deschamps), construído com auxílio de IA.

## Stack

- **Next.js** com App Router (diretório `app/`)
- **React**
- **JavaScript** (sem TypeScript)
- Gerenciador de pacotes: **npm** (`package-lock.json`)

## Comandos

```bash
npm run dev     # servidor de desenvolvimento
npm run build   # build de produção
npm run start   # servir o build de produção
```

## Convenções

- Interface e textos em português (pt-BR).
